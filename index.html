📄 1. PDF 전문 도구 (9종)

  • PDFPDF 병합 (PDF Merge): 여러 개의 PDF 문서를 원하는 순서대로 자유롭게 배치하여 하나의 통합 PDF 파일로 초고속 결합합니다.
  • PDFPDF 용량 줄이기 (PDF Compress): 텍스트 선명도를 보존하면서 최대 80% 용량을 압축하여 이메일 첨부 제한을 해결합니다.
  • PDFPDF 페이지 회전 (PDF Rotate): 거꾸로 스캔되었거나 가로로 누운 문서를 90도, 180도 바르게 영구 정렬합니다.
  • PDF이미지 ➔ PDF 변환 (Image to PDF): JPG, PNG, WEBP 사진들을 A4 규격의 고화질 전자책 및 보고서 PDF로 묶어줍니다.
  • PDFPDF ➔ 이미지 변환 (PDF to Image): PDF 문서의 각 페이지를 2.0x 고해상도 PNG 이미지로 렌더링하여 개별 또는 ZIP으로 다운로드합니다.
  • PDFPDF 페이지 추출 (Extract PDF): 두꺼운 책이나 논문에서 원하는 페이지만 쏙쏙 골라내어 새 PDF로 분리합니다.
  • PDFPDF 여백 자르기 (Crop PDF): 상/하/좌/우 불필요한 스캔 테두리 여백을 시각적으로 확인하며 잘라내어 가독성을 높입니다.
  • PDFPDF & 이미지 OCR 글자 인식 (OCR PDF): 스캔 이미지 속 글자를 인식하여 텍스트로 추출하고 검색 가능한 Searchable PDF를 만듭니다.
  • PDFPDF 암호 설정 및 해제 (PDF Protect & Unlock): 강력한 256-bit 보안 암호를 설정하거나 기존 암호를 제거합니다.

🖼️ 2. 이미지 & AI 도구 (6종)

  • IMAGEAI 이미지 누끼 제거 (AI Background Remover): 온디바이스 딥러닝 신경망이 인물, 동물, 상품 배경을 0.1초 만에 투명 PNG로 분리합니다.
  • IMAGEQR 코드 생성기 (QR Code Generator): URL, Wi-Fi 자동 접속, 전화번호를 예쁜 색상과 고해상도 인쇄용 QR 이미지로 만듭니다.
  • IMAGE이미지 용량 줄이기 (Image Compress): 시각적 화질 손실 없이 용량을 대폭 경량화하여 웹 로딩 속도를 최적화합니다.
  • IMAGE이미지 포맷 변환 (Image Converter): PNG ⇄ JPG ⇄ WEBP 형식을 클릭 한 번으로 상호 변환합니다.
  • IMAGE이미지 해상도 조절 (Image Resize): 가로/세로 픽셀(px) 및 비율을 유지하며 고품질 보간법으로 리사이즈합니다.
  • IMAGE파비콘 생성기 (Favicon Generator): 웹사이트에 필요한 favicon.ico 및 애플 터치 아이콘 풀 패키지를 원클릭 생성합니다.

🎬 3. 미디어 & 비디오 도구 (6종)

  • MEDIA움짤 GIF 제작기 (GIF Maker): 연속 사진들을 모아 프레임 속도와 화질을 조절하며 나만의 고화질 GIF 짤을 제작합니다.
  • MEDIA동영상에서 MP3 추출 (Video to MP3): MP4, WebM, MOV 영상에서 순수 오디오 트랙만 무손실 320kbps 음원으로 추출합니다.
  • MEDIA오디오 구간 자르기 (Audio Cutter): 음악의 하이라이트 구간을 시각적 파형을 보며 0.01초 단위로 잘라 스마트폰 벨소리를 만듭니다.
  • MEDIA동영상 구간 자르기 (Video Cutter): 비디오의 불필요한 앞뒤 부분을 프레임 단위로 트리밍하여 가볍게 저장합니다.
  • MEDIA오디오 포맷 변환 (Audio Converter): MP3, WAV, OGG 간의 상호 변환을 지원합니다.
  • MEDIA동영상 포맷 변환 (Video Converter): MP4, WebM 비디오 규격을 서버 업로드 없이 초고속으로 변환합니다.

  • TEXT글자수 & 바이트 세기 (Text Counter): 공백 포함/제외 글자 수, UTF-8 바이트(Byte), 단어 수, 예상 읽기 시간을 실시간 계측합니다.
  • TEXTJSON 정렬 및 검증 (JSON Formatter): 한 줄로 압축된 복잡한 JSON 코드를 들여쓰기 정렬하고 구문 오류(Syntax Error)를 자동 감지합니다.
  • TEXT텍스트 차이점 비교 (Text Diff Checker): 두 문장이나 계약서 수정본에서 달라진 단어와 글자만 색상으로 핀포인트 대조합니다.

Q1. 정말로 내 파일이 외부 서버로 업로드되지 않나요?

WebToolHub의 모든 웹 유틸리티는 횟수 제한 없는 평생 100% 무료 서비스입니다.

Q3. 스마트폰이나 태블릿에서도 잘 동작하나요?

네! 별도의 앱 설치 없이 모바일 크롬, 사파리, 삼성 인터넷 등 모든 최신 모바일 브라우저에서 완벽하게 최적화되어 지원됩니다.

Q4. 처리할 수 있는 파일 크기에 제한이 있나요?

서버 트래픽에 의한 인위적 용량 제한은 전혀 없으며, 사용하시는 PC/스마트폰의 메모리가 허용하는 한 기가바이트(GB) 단위 대용량 파일도 작업 가능합니다.
